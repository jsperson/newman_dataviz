# Newman Data Analytics Seminar / Data Visualization

Coursework repository for Newman University's **Data Analytics Seminar**. The repo is organized by Canvas module and contains Power BI projects, presentations, data extracts, notes, and the final SpaceX dashboard project.

## Repository layout

```text
.
├── module-01-analytical-questions/
├── module-02-audience-explanatory-analysis/
├── module-03-story-and-data-modeling/
├── module-04-story-presentation/
├── module-05-story-review-feedback/
├── module-06-data-dashboards/
├── module-07-dashboard-design-presentation/
└── module-08-final-story-presentation/
```

## Canvas module map

| Canvas module | Repository folder | Typical artifacts |
|---|---|---|
| Module 1: Define Analytical Questions and Begin Explanatory Analyses | `module-01-analytical-questions/` | Superstore exploration and source data. |
| Module 2: Define Your Audience & Develop Explanatory Analysis | `module-02-audience-explanatory-analysis/` | Superstore Power BI iterations and formatting work. |
| Module 3: Crafting the Story | `module-03-story-and-data-modeling/` | Bike sales project, star schema presentation, and Power BI learning resources. |
| Module 4: Tell the Story | `module-04-story-presentation/` | Constructed-field and deep-dive Power BI reports. |
| Module 5: Story Review and Feedback | `module-05-story-review-feedback/` | Knaflic notes and Bike Sales slicer/KPI/filter-context report. |
| Module 6: Data Dashboards | `module-06-data-dashboards/` | Northwinds dashboard connection work. |
| Module 7: Dashboard Design & Presentation | `module-07-dashboard-design-presentation/` | Northwinds mockup and drill-through reports. |
| Module 8: Final Story Presentation | `module-08-final-story-presentation/` | SpaceX dashboard, metrics notes, theme, and dimensional/fact CSVs. |

## Notes

Power BI `.pbix` files are binary; meaningful review usually happens by opening the reports in Power BI Desktop. Markdown files in the final module document measures, improvement analysis, and session context.
